# Перенос проекта на другой ПК

## Что перенести

Скопируй всю папку `bot2` на новый компьютер, включая скрытый файл `.env`.

`.env` содержит токен Telegram и ключ Mistral. Передавай его только через безопасное хранилище или флешку; не отправляй в мессенджерах и не добавляй в Git.

Не нужно переносить:

- `.venv` — на новом ПК она создаётся заново;
- `__pycache__`;
- папку `data`, если она появилась только после локальных тестов.

## На новом ПК

1. Установи Python 3.12 или новее.
2. Открой PowerShell в папке проекта.
3. Выполни:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

4. Убедись, что рядом с `bot.py` лежит твой настоящий `.env`.
5. Для локального запуска дважды кликни `start_bot.cmd`.
6. Для работы с сервером установи компонент Windows **OpenSSH Client**: он нужен командам `ssh` и `scp` в `update_beget.cmd`.
7. Открой проект в Codex и используй текст из `PROMPT_FOR_FUTURE_CODEX.md`.

## Сервер и память пользователей

Переезд на другой ПК не затрагивает работающий Beget VPS и память бота: она хранится в Docker volume `bot-memory` на сервере.

Не запускай на VPS `docker compose down -v`, иначе память будет удалена.

Если когда-нибудь понадобится переносить сам VPS на другой сервер, сначала сделай резервную копию volume. Это отдельная операция — попроси Codex подготовить её и проверь результат до удаления старого сервера.

## Проверка после переноса

Отправь боту:

```text
/start
/memory
Привет
```

Если бот отвечает, перенос успешен. Для загрузки новых изменений на VPS используй `update_beget.cmd`.
