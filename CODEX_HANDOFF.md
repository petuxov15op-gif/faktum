# Передача проекта следующему Codex

## Что это

Telegram-бот на Python. Он общается на русском в дружеском стиле, отвечает через Mistral, хранит память каждого пользователя и использует встроенный веб-поиск Mistral для актуальных или проверяемых данных.

Рабочая папка проекта: `C:\Users\max\Documents\bot2`.

## Текущая архитектура

- `bot.py` — весь код бота.
- `aiogram` — Telegram long polling.
- `aiohttp` — запросы в Mistral API.
- Mistral Chat Completions — обычные ответы.
- Mistral Conversations + `web_search` — поиск актуальной информации.
- OpenRouter Chat Completions — отдельный тестовый ответ только по команде `/openrouter` или `/or`; история и сохранённые факты Mistral туда не передаются.
- SQLite — память и лимиты пользователя.
- Docker Compose — работа на Beget VPS.

Используется только Mistral. OpenRouter, Qwen и Tavily были пробованы ранее, но удалены из рабочего пути:

- OpenRouter с VPS возвращал `Access denied by security policy`.
- Tavily с VPS возвращал `HTTP 403`.
- Папка `n8n/` — старый неиспользуемый workflow, не менять без отдельного запроса.

Пользователь 06.08.2026 явно попросил временно вернуть OpenRouter вторым провайдером для проверки. По умолчанию он использует `openai/gpt-oss-20b:free`; основной путь и веб-поиск всё ещё работают через Mistral. Не переключать провайдер по умолчанию без отдельного запроса.

## Что уже реализовано

- Дружеский системный промт с допустимым уместным разговорным стилем.
- Обычный диалог, `/start`, `/help`.
- Команды `/menu`, `/search`, `/new`, `/memory`, `/remember`, `/forget`, `/reset`, `/hide`.
- Меню открывается только через `/menu`; не должно автоматически появляться после каждого ответа.
- Обычная память: последние 12 сообщений передаются модели, до 100 сообщений хранится на пользователя.
- Долговременные факты: `/remember текст`, просмотр через `/memory`.
- `/new` очищает только текущую историю; `/forget` удаляет историю, факты и лимиты пользователя.
- SQLite использует WAL; на VPS база находится в Docker volume `bot-memory`.
- Лимиты по пользователю: запросы в минуту, в день, веб-поиски в день.
- Повторные попытки запросов Mistral при временных сетевых ошибках.
- Статус Telegram «печатает…» во время ответа.
- Строгий режим фактов (`STRICT_FACT_MODE=true`): вопросы с датами, месяцами, годами, событиями, ценами, людьми и другими фактами направляются в веб-поиск.
- Для афиш/концертов выполняются два веб-поиска: основной и фактчек. Если источников нет, бот должен сказать, что не нашёл подтверждения, а не выдумывать ответ.
- Москва задаётся фиксированным UTC+3 без `zoneinfo`, чтобы Docker не падал на отсутствии `tzdata`.

## Хронология запросов и решений

1. Изначально пользователь хотел бота из ТЗ проекта и рассматривал n8n. n8n оказался ненадёжным, поэтому сделан отдельный Python-бот.
2. Пробовали OpenRouter и разные модели, но с Beget VPS OpenRouter возвращал `Access denied by security policy`.
3. Пробовали Tavily для поиска, но с Beget VPS он возвращал `HTTP 403`.
4. Пользователь рассматривал Qwen/Alibaba Cloud, но регистрация и верификация оказались неудобными. Qwen и OpenRouter удалены из рабочего пути.
5. Выбрали прямой Mistral API. Локальная проверка Mistral и его веб-поиска прошла успешно.
6. Бот развёрнут на Beget VPS в Docker через `update_beget.cmd`. Ранее была ошибка записи `bot.log` из-под непривилегированного Docker-пользователя; её устранили переходом на stdout-логи.
7. Пользователь попросил дружеский стиль. Полный утверждённый системный промт находится в `SYSTEM_PROMPT` в `bot.py`; его нельзя самовольно сокращать или заменять без запроса.
8. Пользователь попросил память. Добавлены SQLite-история, профиль фактов и команды памяти.
9. Пользователь попросил убрать навязчивое меню. Сейчас меню открывается только через `/menu`, а скрывается через `/hide`.
10. Пользователь обнаружил неверную афишу и ложную дату «Уральской ночи музыки». Добавлены строгая маршрутизация дат/событий в поиск, повторная проверка афиш и безопасный отказ без источников.

## Важное ограничение достоверности

LLM и веб-поиск не могут дать математическую гарантию истины. Mistral уже однажды уверенно выдумал дату «Уральской ночи музыки», когда сообщение с поправкой пользователя не ушло в веб-поиск. Это исправлено в маршрутизации дат и событий.

Если дорабатываешь поиск или ответы про мероприятия:

1. Предпочитай официальный сайт организатора, площадки или администрации города.
2. Не выдавай страницы прошлых лет за будущие анонсы.
3. Без источника возвращай честное «не удалось подтвердить».
4. Не обещай пользователю абсолютную гарантию отсутствия ошибок.

## Настройки `.env`

Реальный `.env` содержит секреты и не должен попасть в Git, чат или документацию. Шаблон — `.env.example`.

Обязательны:

```env
TELEGRAM_BOT_TOKEN=
MISTRAL_API_KEY=
```

Основные необязательные настройки:

```env
MISTRAL_MODEL=mistral-small-latest
OPENROUTER_API_KEY=
OPENROUTER_MODEL=openai/gpt-oss-20b:free
TELEGRAM_PROXY_URL=
MEMORY_DB_PATH=data/bot_memory.sqlite3
REQUESTS_PER_MINUTE=6
REQUESTS_PER_DAY=100
WEB_SEARCHES_PER_DAY=25
STRICT_FACT_MODE=true
LOG_LEVEL=INFO
```

Для Docker на VPS путь памяти принудительно задаётся как `/data/bot_memory.sqlite3` в `docker-compose.yml`.

## Запуск и обновление

Локально:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
.\.venv\Scripts\python.exe bot.py
```

Или двойной клик по `start_bot.cmd` после создания `.venv` и `.env`.

Обновление VPS: двойной клик по `update_beget.cmd`. Скрипт загружает `bot.py`, `Dockerfile`, `docker-compose.yml` и `.env`, затем пересобирает и перезапускает контейнер. VPS-пароль знает пользователь; Codex не должен его запрашивать или хранить.

Не выполняй `docker compose down -v`: эта команда удалит named volume с памятью пользователей.

## Как безопасно работать дальше

1. Сначала прочитай `bot.py`, затем только нужные документы.
2. Перед изменением проверь, не просит ли задача дополнительные ключи или платные API.
3. Для изменений Python запускай `.\.venv\Scripts\python.exe -m py_compile bot.py`.
4. Проверяй новые функции локально без печати секретов.
5. После изменений напомни пользователю запустить `update_beget.cmd`.
6. Говори по-русски, кратко и конкретно. Пользователь не любит длинные ручные инструкции.
